My lighting: None selected

Surface PAR for each light is a rough estimate for one fixture at 100%. Settings above 100% only apply to lights that allow overdrive. Extra fixtures are assumed to add about half their output where beams overlap, and they also widen the lit area. Recommended light counts use rough coverage estimates for each fixture. Height, lens, tank size and settings change it a lot, so use a PAR meter if you can and choose Custom.

Your selections save automatically on this device.

Firefox cannot save to a file automatically. If it clears its data when it closes, press this to download a copy of the app with your selections built in, then replace your index.html with it. You can also stop Firefox clearing data under Settings > Privacy & Security > Cookies and Site Data (untick Delete cookies and site data when Firefox is closed).

On a computer, Chrome and Edge can save automatically to a file you choose. This keeps your data even if the browser clears its storage. Create a file once, then use Open save file next time.
